# Memora Pitch Package Notes

## Included Files

- `final/Memora_Intern_Recruiting_Deck.pptx`  
  Recruiting deck for new graduates, focused on the product mission, architecture, project tracks, and what interns will learn.

- `final/Memora_Investor_Pitch_Deck.pptx`  
  Investor deck focused on the problem, target customer, product wedge, MVP scope, differentiation, roadmap, business model, use of funds, and funding ask.

- `final/Memora_Investor_Pitch_Deck_Black_Theme.pptx`  
  Full-black investor deck variant for external circulation and pitch-room use.

- `web/index.html`  
  Self-contained browser presentation with Interns and Investors modes.

- `assets/`  
  Generated visual assets used by the decks and browser presentation.

## Product Naming

The user-facing deck name is `Memora`. The source PRD uses `Memoryhive`; the decks standardize on `Memora` and cite the PRD in speaker notes.

## Investor Deck Placeholders To Confirm

- Round amount
- Valuation and terms
- Planned runway
- Beta user count or pilot list
- Current app completeness against the README roadmap
- Pricing assumptions for sync and AI tiers
- Any real traction, retention, activation, or willingness-to-pay data

## Recommended Live Demo Flow

1. Save a screenshot from mobile.
2. Save a link from a browser or social app.
3. Show local search finding extracted screenshot text.
4. Show item detail with source, timestamp, summary, and tags.
5. Show export or delete control to reinforce data ownership.
